# Ru Android Project

Android приложение на Kotlin.

## Структура проекта

- `app/` - основной модуль приложения
- `gradle/` - конфигурация Gradle wrapper
- `build.gradle.kts` - файл конфигурации для корневого проекта
- `settings.gradle.kts` - настройки проекта

## Требования

- Java 11 или выше
- Android SDK 34
- Gradle 8.1

## Сборка

```bash
./gradlew build
```

## Запуск

```bash
./gradlew assembleDebug
```
